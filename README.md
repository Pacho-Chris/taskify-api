## Descripción

**Taskify API** es un backend robusto y escalable desarrollado bajo los más altos estándares de arquitectura y calidad de software.

**Características principales:**
* ⚙️ **Arquitectura Modular:** Estructura limpia basada en NestJS y Prisma ORM.
* 🛡️ **Calidad de Código Automatizada:** Integración de Husky, Lint-Staged, ESLint y Prettier para validar el código antes de cada commit.
* 📝 **Conventional Commits:** Estandarización del historial de cambios mediante Commitlint con tipos y alcances definidos (`feat`, `fix`, `chore`, `ci`, etc.).
* 🔒 **Seguridad y Buenas Prácticas:** Autenticación JWT, validación estricta de DTOs y manejo de entornos de desarrollo profesionales.

## Project setup

```bash
pnpm install
```

## Compile and run the project

```bash
# development
pnpm run start

# watch mode
pnpm run start:dev

# production mode
pnpm run start:prod
```

## Run tests

```bash
# unit tests
pnpm run test

# e2e tests
pnpm run test:e2e

# test coverage
pnpm run test:cov
```
